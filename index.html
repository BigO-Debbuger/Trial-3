🤖 AI Disclosure

AI Components

  • Strategy Engine: The enemy AI uses a 6-step pipeline (SCAN → EVALUATE → PLAN → SCORE → EXECUTE → LEARN) to select attack strategies.
  • LLM Integration (Optional): When connected, OpenAI via Swytchcode provides enhanced strategy reasoning.
  • Adaptive Learning: The AI remembers previous attack outcomes and adjusts weights to try different strategies when others fail.

Deterministic Components

  • Combat Resolution: All damage calculations use deterministic formulas with controlled random variance (±15%).
  • Resource System: Income, costs, and building stats are fixed values.
  • Game Rules: Turn limits, building placement, and win/loss conditions are fully deterministic.

Swytchcode Role

Swytchcode sits between the game and OpenAI, handling authentication, execution policy, and retries. The LLM never modifies game state directly — all strategies are validated before execution.
